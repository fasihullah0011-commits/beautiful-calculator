# ✨ Beautiful Calculator

A small, clean calculator app project designed to make everyday arithmetic feel simple and pleasant.

> **Project status:** Starter project. The repository currently contains this README; the calculator app itself has not been added yet.

## 🌿 The idea

Build a lightweight calculator with a polished, responsive interface and the essential operations you need for quick calculations—without unnecessary clutter.

## 🎯 Planned features

- Addition, subtraction, multiplication, and division
- Clear and delete controls
- Keyboard-friendly input
- Responsive layout for desktop and mobile
- A simple, accessible interface

## 🧰 Planned stack

The app is intended to be a small web project using **HTML, CSS, and JavaScript**, with no framework or build step required.
